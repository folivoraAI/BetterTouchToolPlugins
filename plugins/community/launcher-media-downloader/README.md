# Media Downloader

A BetterTouchTool Launcher plugin for downloading video or audio from YouTube, Facebook, Instagram, TikTok and many other yt-dlp supported sites.

## Features

- Video / Audio mode
- Format dropdown
- Thumbnail preview
- Live progress bar
- Speed and ETA
- Choose download folder
- Update yt-dlp / FFmpeg
- Copy last log

## Requirements

- BetterTouchTool with Swift plugins enabled
- Homebrew
- yt-dlp
- ffmpeg
- ffprobe

Only download media you own or have permission to download.
